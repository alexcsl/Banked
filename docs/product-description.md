# Banked product description

## Short description

Set a SOL balance to keep, then route only the excess through a wallet-approved exit plan on Solana.

## Long description

Banked helps traders follow through on a decision made before the next trade. Set how much SOL you want to keep in your wallet, choose where the excess should go, and activate the rule when you are ready. If your keep amount is 10 SOL and your wallet holds 9, Banked proposes no sale. At 11 SOL, only the extra 1 SOL is eligible for the exit plan. You can pause a rule to edit it or leave the full wallet balance under your control.

When you choose to execute, Banked checks the current wallet balance and prepares a SOL-to-USDC sale for your review. The USDC received is split according to your plan: a portion can go toward SPYx, a portion toward JUP, and the rest stays as USDC. You approve each transaction separately. A dashboard and saved receipts show which purchases were completed, which still need action, and how much USDC was planned to remain.

Banked uses Solana so the SOL sale, USDC proceeds, and eligible token destinations can be reviewed from the same wallet. The current working demo is a simulation with clearly labeled synthetic proceeds. Live execution is gated while transaction inspection, reconciliation, provider access, and eligibility are validated. Activating a rule does not automatically monitor or spend from the wallet.
